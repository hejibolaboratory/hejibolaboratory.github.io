02 Typography

专用字形

品牌手册规定：中文使用 HarmonyOS Sans SC，英文使用 Futura Condensed Medium； 整体简洁的笔画造型与无装饰感的字形符合品牌“柔性、自然、温暖”的调性。

字体栈

CN: HarmonyOS Sans SC → PingFang SC → Hiragino Sans GB → Noto Sans SC
EN: Futura Condensed Medium → Futura → Avenir Next Condensed

不使用外部字体 CDN：优先调用系统已有字体，保证在境内网络下也能一次性渲染完成。

Display / clamp(2.05–3.6rem)

从被陪伴阅读，到独立思考

H2 / clamp(1.5–2.3rem)

八个阶段，一条看得见的成长路径

H3 / clamp(1.12–1.375rem)

主题共读 II · 拼读桥梁

Lead / 1–1.15rem · 行高 1.85

年龄是建议区间；真正的起点由阅读表现、学习状态与作品样本共同决定。

Body / 0.95–1.06rem · 行高 1.78

每一阶段都同时推进阅读、思考与表达，成果以可观察证据呈现。

Eyebrow / Futura · 0.78rem · 字距 .2em

03 Identity

标识使用

品牌标识有横版与竖版组合。浅色底使用全彩（墨黑）标识，深色底使用反白标识； 周边保留不小于“x”的安全空间，不做拉伸、描边、换色处理。

浅色底：使用全彩标识。文件 assets/img/logo.png（透明底）。

深色底：使用反白标识。文件 assets/img/logo-light.png（透明底）。

✦ 矢量原文件请使用品牌手册中的电子原图（.ai / .eps）。本页位图由品牌素材导出， 正式上线建议替换为矢量 SVG，以获得任意尺寸下的清晰度。

04 Components

组件

按钮

最小点击高度 48px（小号 40px）；圆角全圆；悬停上移 2px；键盘焦点使用 3px 描边。

标签与徽章

默认标签 强调标签 2–12 岁

标签不用于按钮；可横向滚动以避免换行挤压。

卡片

白底、1px 描边、圆角 26px、内距随视口缩放。悬停时上移 3px 并出现阴影； 顶部强调卡（card--accent）用 3px 品牌金内描边标示层级。

表单

说明文字使用 0.8125rem 次级色。

05 Responsive

响应式规则

移动优先：基础样式面向手机，逐级向上增强。字号与间距全部使用 clamp() 流式缩放， 因此从 320px 到 1920px 之间不需要“跳变”的中间状态。

断点与布局变化
断点设备布局变化
默认 手机 320–639px 单列；导航收进抽屉；底部固定行动条（电话 + 预约）；表格可横向滑动；卡组 2 列或 1 列。
≥ 640px 大屏手机 / 平板竖屏 数据条 4 列；图集 3 列（首图放大占 2×2）；表单两列；多列卡组 3 列；步骤 2 列。
≥ 900px 平板横屏 / 小笔记本 顶部导航展开、隐藏汉堡与底部行动条；Hero 与内容区变两栏；侧栏吸顶；路径卡 4 列。
≥ 1200px 桌面 导航间距放大；页脚 4 栏；内容最大宽度收在 1220px，保证行长舒适。

栅格

卡组使用 auto-fit + minmax(min(100%, 250px), 1fr)，容器变窄时自动减少列数，不会出现内容溢出。

图片

统一由 aspect-ratio 固定比例 + object-fit: cover，非首屏图片使用 loading="lazy"。

表格

宽表在窄屏横向滚动，表头不换行；同时在表格上方提示可左右滑动。

触控

可点击元素最小 44×44px；移动端抽屉与底部行动条计入 env(safe-area-inset-bottom)。

06 Accessibility

无障碍与降级

对比度

正文文字控制在 4.5:1 以上；品牌金与古铜金仅用于大字号或图形，不用于小号正文。

键盘可达

提供“跳到主要内容”链接；标签页支持 ← → / Home / End；抽屉与灯箱可用 Esc 关闭。

动效降级

尊重 prefers-reduced-motion：关闭滚动入场与位移过渡，保留内容呈现。

无脚本可用

FAQ 使用原生 details；成长路径首个阶段默认展示；所有内容不依赖 JS 获取。
