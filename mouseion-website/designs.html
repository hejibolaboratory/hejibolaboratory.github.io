书院金 · 基准方案

暖纸底 + 墨黑 + 品牌金，编辑排版感

最贴近品牌手册的一套：稳、耐看、信息承载量大。第一眼传达的是 “这是一家有积累、有标准的机构”。

  • 关键词暖纸白 / 品牌金 / 编辑栅格 / 大量留白 / 克制细节
  • 适合以“专业、权威、国际视野”为主诉求；中高年级家长占比较高
  • 优点品牌还原度最高；内容密度高不易过时；9 个页面已可直接进入开发
  • 风险气质偏稳，低龄家长第一眼的惊喜感一般

B

童趣乐园

圆润有机形状 + 品牌四色铺陈

让孩子一眼想进去，让低龄家长感到温暖、有趣、不焦虑。 第一眼传达的是“这里很好玩，孩子会喜欢来”。

  • 关键词大圆角 / 有机形状 / 贴纸标签 / 四色拼接 / 轻动效
  • 适合2–8 岁启蒙与兴趣导向；重视到店引流与社媒传播
  • 优点亲和力与记忆点最强；在家长信息流里更抓眼；海报易延展
  • 风险中高年级家长可能觉得学术感不足；颜色多，长期使用需守住规范
  • 规范提示中文改用圆体（系统 Yuanti SC 等），与品牌手册的 HarmonyOS Sans SC 不一致，需品牌方确认是否开放

数据可信

深色仪表盘质感 + 真实图表

把成长阶段、课时投入与升阶门槛做成可读的数据。 第一眼传达的是“我们把每一步说清楚，进步可以被查看”。

  • 风险深色在户外手机阅读略费眼；数据必须真实且可长期维护，否则反噬信任

专业体系

参照头部原版阅读机构官网结构

分段色带 + 大号数字 + 三阶段课程体系 + 素养课网格，是目前家长最熟悉、 也最容易快速看懂的“教育机构官网”语言。第一眼传达的是“体系完整、可报名”。

  • 参照样本厚海阅读（houhaienglish.com）——国内头部英语原版阅读机构

Recommendation

怎么选：按目的而不是按喜好

建议先确定这一年的网站目标，再回头选方案。

如果目标是“让家长放心、把课程说清楚”

选 A · 书院金。它信息层级最完整，家长能在两屏内判断“这里教什么、怎么教、怎么证明”。 可以吸收 B 的贴纸标签，用在低龄阶段区块上，给启蒙课一点活泼感。

如果目标是“到店引流、低龄启蒙”

选 B · 童趣乐园。适合投放在家长社群与朋友圈，第一眼阻力最小； 配合活动海报与假期营，转化路径最短。建议同时保留 A 的部分严谨表述，避免显得“只是玩”。

如果目标是“和学科机构正面竞争”

选 C · 数据可信。把 M0–M7 阶段、课时投入、测评门槛公开对照， 回应“读了这么久到底有没有用”。注意：页面上每一个数字都必须能长期维护。

如果目标是“品牌升级、媒体与社媒传播”

选 D · 杂志画册。空间本身就是卖点，适合做媒体稿件、榜单与短视频素材的落点。 前提是补拍一组高质量空间与课堂照片。

如果目标是“招生转化、让家长快速看懂体系”

选 E · 专业体系。这是参照头部原版阅读机构（厚海阅读）的结构做的： 分段色带、三阶段课程体系、级别明细、素养课网格、页面底部直接留资。 家长获取信息的效率最高，代价是与同类机构官网相似度较高。

我们更推荐的组合：A 作为全站主体框架（可信、完整、易维护）， 在“课程体系”页采用 E 的体系表达方式（三阶段 + 级别明细 + 素养课网格）， D 的空间与活动章节放大图片张力，B 的色块与贴纸只用在 2–8 岁低龄课程页。 这样既有稳定骨架，又能在最需要“抓眼”和“说清体系”的地方各司其职，后期换皮肤不动内容。
✦ 如果只能选一套：偏品牌与信任选 A，偏招生转化选 E， 偏低龄引流选 B，偏差异化竞争选 C，偏形象升级选 D。
